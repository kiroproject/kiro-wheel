# История изменений

Формат: новые версии сверху. Подробный список коммитов смотрите в истории репозитория.

## 1.8.0 — 2026-10-07

### Добавлено
- Аудитория призов. В админке у каждого приза появилось поле «Кому доступен приз»: без подписки, пробная подписка (триал), платная подписка и, по желанию, список конкретных тарифов Minishop (список берётся из тарифов Minishop, ничего не зашито в плагине). Приз попадает в розыгрыш и на барабан игрока только если его категория входит в аудиторию. Для призов «дни» и «трафик» нельзя выбрать «без подписки», для Premium-трафика доступны только платные тарифы с Premium. Аудитория проверяется ещё раз при получении приза и при активации подарка (по получателю): если подписка игрока изменилась, приз остаётся ожидающим, подарок не списывается.
- Новый запрос админки `GET /api/admin/kiro-wheel/tariffs` (ключ, название, ГБ в месяц, признак Premium) и список тарифов в ответе `overview`.
- Миграция `kiro-wheel.0005_prize_audience` (в планах значилась как 0003, но 0003 и 0004 уже заняты): добавляет существующим призам явную аудиторию, равную прежней фактической доступности (дни и трафик: пробная и платная; Premium: платная; остальные типы: все). Миграция безопасна для повторного запуска и ничего не удаляет. Новый параметр `trial_convert_tariff` в настройках (по умолчанию `start`) добавляется без миграции.
- Приз «дни подписки» для игрока на пробном периоде заменяет триал платным базовым тарифом ровно на N дней с момента получения (остаток триала не прибавляется). Тариф выбирается в настройках плагина («Тариф по умолчанию вместо пробного периода») и может быть переопределён в самом призе. Результат такой же, как при ручной смене тарифа в админке: сквады тарифа вместо пробных, лимит трафика, число устройств и тег тарифа, счётчик трафика обнулён, подписка больше не пробная (запись остаётся, повторный триал недоступен). Пометка «выдано колесом»: в карточке подписки `tariff_binding_note = kiro-wheel:trial_convert:…`, в результате вращения (`converted_trial`), в списке последних вращений и в журнале плагина (событие `trial_converted`). Игрок перед получением видит, каким тарифом будет заменён триал.
- Приз «Premium-трафик» теперь зачисляется сразу тем же способом, что «пополнение Premium» в админке (баланс Premium, Premium-сквад, запись о пополнении), и только игрокам на платном тарифе с Premium-сквадом. Если Core не смог применить пополнение, приз остаётся ожидающим.
- Подарки: сегмент определяется по получателю. Если приз ему не подходит (Premium для триала, дни без подписки, аудитория приза), показывается понятная причина, а подарок остаётся нетронутым.
- Тесты `tests/run_audience_tests.py` (аудитории, миграция, сегменты, замена триала, Premium, трафик на триале, подарки, откаты при ошибках).

### Исправлено
- Приз «дни» или «трафик» на пробной подписке больше не сбрасывает лимит трафика триала в «безлимит», число устройств на значение по умолчанию и тег TRIAL (так вело себя штатное начисление Core: его синхронизация лимита считает базой для подписки без тарифа 0). Дни на триале теперь заменяют триал тарифом, а обычный трафик на триале добавляется отдельным запросом к панели, в котором меняется только лимит трафика (лимит триала плюс накопленный бонус); сквады, устройства, тег и срок не затрагиваются. Ошибка панели откатывает выдачу, повторная попытка даёт тот же итог. Для платных подписок поведение прежнее. Ошибка самого Core при ручном начислении дней или трафика пробной подписке вне колеса остаётся и исправляется в Core.
- Версия внутри плагина (`KiroWheelPlugin.version`, раньше 1.7.1) выровнена с версией пакета.
- На безлимитном тарифе приз «трафик» больше не начисляется: Core поднимал лимит и подписка начинала ограничиваться. Такой приз не выпадает на барабане, а если он был выигран до смены тарифа, подарить или перекрутить его можно, как и остальные недоступные призы.
- Если у колеса 0 бесплатных вращений в день, карточка больше не пишет «Следующее вращение через …» с таймером до полуночи: такого вращения не будет. Вместо таймера показывается «Нет доступных вращений».

### Изменено
- На барабане игрок видит только призы, доступные его категории.
- У Premium-трафика больше нет срока действия кода (приз начисляется сразу).

## 1.7.4 — 2026-10-07

### Исправлено
- Игроку с пустым значением `is_banned` (`NULL`) в таблице пользователей больше не отказывают с сообщением «Профиль не найден». Пустое значение считается «не заблокирован», как и в ядре Minishop. Проявлялось у тех, у кого `is_banned` в базе не заполнен (например, после переноса данных). Править данные в базе не нужно.

## 1.7.1 — 2026-10-06

### Добавлено
- **Журнал плагина** в админке: ошибки, отказы, вращения, ежедневные награды, подарки, начисления за оплату и действия администратора. Можно скачать отчёт для поддержки (ID пользователей и коды подарков скрыты), скопировать его, очистить журнал и отфильтровать по уровню.
- Настройка «Подробный журнал» для диагностики.

### Изменено
- Вместо общего «Доступ ограничен» игрок видит причину: «Аккаунт заблокирован» или «Профиль не найден». Кнопки вращения и ежедневной награды в этих случаях сразу недоступны.
- Новая таблица в базе данных (миграция `kiro-wheel.0004_journal`), применяется автоматически.

## 1.7.0 — 2026-10-02

### Добавлено
- **Календарь ежедневных наград**: серия из 7 дней, за каждый заход игрок получает билетики (бонусные вращения), пропуск дня сбрасывает серию. Награды по дням настраиваются в админке.

### Изменено
- Когда календарь включён, бесплатное вращение раз в сутки не выдаётся.
